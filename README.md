# Grama Khata – Digital Credit Ledger

## Problem
Village shopkeepers use physical books for credit tracking which leads to loss and confusion.

## Solution
A simple digital ledger to:
- Add customers
- Track credit/debit
- Show total due
- Generate reminder message

## Features
- Customer profile (basic)
- Credit (+) / Debit (-)
- Auto balance calculation
- Reminder message generator

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download project
2. Open index.html in browser
